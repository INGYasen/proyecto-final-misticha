# Problema de Negocio

## Contexto

El Perú posee una tradición textil y artesanal reconocida por la calidad de sus materiales, sus técnicas de producción y su identidad cultural. Sin embargo, muchos artesanos comercializan sus productos de manera independiente y dependen de canales limitados, como:

- Ferias artesanales.
- Mercados locales.
- Tiendas físicas.
- Intermediarios.
- Actividad turística.

Este modelo reduce la capacidad de llegar a nuevos clientes y dificulta la consolidación de una oferta organizada bajo una marca común.

## Problema principal

La producción artesanal peruana carece, en muchos casos, de una plataforma centralizada que permita registrar a los productores, controlar el origen y la calidad de las prendas, administrar el inventario y organizar su comercialización digital.

Esta falta de integración produce una separación entre las diferentes etapas del negocio:


Artesano → Acopio → Inventario → Catálogo → Venta → Pago

## Problemas específicos

### 1. Producción dispersa

Los artesanos trabajan de manera independiente y no siempre siguen un proceso unificado de registro, entrega y control de sus productos.

Esto dificulta:

- Identificar al proveedor de cada lote.
- Conocer la comunidad o zona de procedencia.
- Registrar las cantidades recibidas.
- Mantener el historial de compras realizadas al artesano.
- Conservar la trazabilidad de las prendas.

Como consecuencia, el negocio no cuenta con una visión clara del origen de cada producto ni del aporte individual de cada artesano dentro de la cadena de producción.

---

### 2. Falta de control de calidad centralizado

Las prendas artesanales pueden presentar diferencias en material, talla, acabado, color, estado o presentación final. Sin un control de calidad centralizado, resulta difícil garantizar que todos los productos publicados cumplan con los criterios definidos por la marca.

Esto dificulta:

- Registrar una inspección por prenda.
- Determinar si una prenda fue aprobada, observada o descartada.
- Mantener evidencias y observaciones del proceso de revisión.
- Evitar la publicación de productos que no cumplen los estándares establecidos.
- Asegurar una experiencia uniforme para el cliente final.

Este problema puede afectar directamente la percepción de calidad de la marca y generar reclamos, devoluciones o pérdida de confianza.

---

### 3. Gestión limitada del inventario

El uso de registros manuales, hojas de cálculo o sistemas separados puede generar inconsistencias en la administración del inventario.

Entre los principales riesgos se encuentran:

- Información de stock desactualizada.
- Duplicidad de códigos de productos.
- Dificultad para clasificar prendas por talla, color, material o estado.
- Ventas de productos sin disponibilidad real.
- Pérdida de relación entre la prenda y su lote de origen.

Una gestión deficiente del inventario puede ocasionar errores en ventas, retrasos en pedidos y pérdida de control sobre los productos disponibles.

---

### 4. Presencia digital insuficiente

Muchos productores y artesanos no cuentan con herramientas digitales para promocionar y vender sus productos de manera profesional.

Generalmente no disponen de:

- Página web propia.
- Catálogo digital actualizado.
- Plataforma de comercio electrónico.
- Administración de precios y promociones.
- Herramientas para llegar a clientes fuera del mercado local.
- Canales digitales para mostrar el valor cultural de sus productos.

Como consecuencia, prendas con alto valor artesanal, cultural y comercial no logran suficiente visibilidad en mercados más amplios.

---

### 5. Procesos comerciales desconectados

Cuando el catálogo, el carrito, los pedidos, el inventario, las ventas y los pagos se administran por separado, pueden aparecer inconsistencias que afectan la operación del negocio.

Algunos problemas frecuentes son:

- Precios diferentes entre el catálogo y el pedido.
- Carritos con productos inexistentes o sin stock.
- Pagos sin relación directa con una venta.
- Pedidos confirmados sin actualizar el inventario.
- Dificultad para consultar el historial de compra del cliente.
- Falta de seguimiento del estado real de una orden.

Esta desconexión reduce la eficiencia del proceso comercial y aumenta la probabilidad de errores operativos.

---

### 6. Control de acceso insuficiente

La información de artesanos, inventario, ventas, pagos y usuarios no debe ser modificada por cualquier persona. El sistema necesita diferenciar claramente los permisos según el tipo de usuario.

El negocio requiere controlar las operaciones permitidas para:

- Clientes.
- Personal de ventas.
- Administradores.
- Consultas públicas.
- Servicios internos del sistema.

Sin un control de acceso adecuado, existe el riesgo de modificaciones no autorizadas, exposición de información sensible o ejecución de operaciones críticas por usuarios no permitidos.

---

## Consecuencias para el negocio

La ausencia de una solución integrada puede generar los siguientes impactos:

| Consecuencia | Impacto en el negocio |
|---|---|
| Menor alcance comercial | Dependencia del turismo y de mercados locales. |
| Poca trazabilidad | Dificultad para conocer el origen de cada prenda. |
| Control de calidad inconsistente | Riesgo de ofrecer productos no aprobados o con observaciones. |
| Errores de stock | Posibilidad de vender productos sin disponibilidad real. |
| Procesos manuales | Mayor tiempo operativo y mayor probabilidad de errores. |
| Información fragmentada | Dificultad para tomar decisiones basadas en datos. |
| Seguridad limitada | Acceso inadecuado a operaciones sensibles del sistema. |
| Escalabilidad reducida | Dificultad para incorporar nuevos procesos, artesanos o canales de venta. |

---

## Oportunidad identificada

Existe una oportunidad importante para conectar la riqueza artesanal peruana con tendencias actuales del mercado nacional e internacional, tales como:

- Moda sostenible.
- Comercio justo.
- Productos con identidad cultural.
- Prendas artesanales de calidad.
- Productos con historia, origen y trazabilidad.
- Comercialización digital.
- Consumo responsable.
- Diferenciación de marca mediante valor cultural.

Raymi Suprême aprovecha esta oportunidad mediante una plataforma que organiza la cadena de valor, centraliza la información del negocio y prepara el sistema para ampliar su alcance comercial.

---

## Enfoque de solución

Para responder a estos problemas, Raymi Suprême plantea una solución basada en una arquitectura de microservicios, donde cada proceso del negocio se administra mediante un módulo especializado.

El sistema permite:

- Registrar artesanos y lotes de producción.
- Gestionar prendas e inventario disponible.
- Publicar productos en un catálogo digital.
- Administrar carritos de compra.
- Generar ventas.
- Procesar pagos.
- Controlar accesos mediante roles.
- Monitorear el estado técnico de los servicios.

De esta manera, la plataforma no solo funciona como una tienda virtual, sino como una solución integral para organizar, controlar y escalar la comercialización de prendas artesanales peruanas.
