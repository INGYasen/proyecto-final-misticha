# Errores frecuentes

- **Angular "port 4200 in use"**: a veces igual responde en http://localhost:4200. Si no, matar el proceso y `npm start` otra vez.
- **Pedido 34 sin items**: no se puede crear preferencia. Hay que armar el pedido desde el carrito.
- **Yape Collector doesn't respond**: Checkout Pro.
- **Al cerrar Cursor se apaga todo**: usar `levantar-stack-independiente.ps1`.
