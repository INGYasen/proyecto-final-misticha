# Decisiones Técnicas

| Tecnología | Motivo de uso |
|---|---|
| Java y Spring Boot | Desarrollo de APIs y microservicios |
| Spring Cloud Gateway | Punto único de acceso |
| Eureka | Descubrimiento de servicios |
| Config Server | Configuración centralizada |
| OpenFeign | Comunicación REST entre servicios |
| Resilience4j | Circuit Breaker y tolerancia a fallos |
| Keycloak | Usuarios, autenticación y roles |
| JWT | Autorización de solicitudes |
| MySQL | Persistencia de datos |
| Flyway | Control de versiones de las bases de datos |
| Docker Compose | Ejecución de la infraestructura |
| Prometheus | Recolección de métricas |
| Loki y Promtail | Centralización de logs |
| Grafana | Visualización y monitoreo |
| Swagger/OpenAPI | Documentación y prueba de endpoints |

## Criterios principales

Las tecnologías fueron seleccionadas para conseguir:

- Separación de responsabilidades.
- Seguridad centralizada.
- Servicios fáciles de mantener.
- Tolerancia a fallos.
- Monitoreo de la plataforma.
- Ejecución en ambientes de desarrollo y producción.
